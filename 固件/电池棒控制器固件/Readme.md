# 电池棒控制器固件操作指引

## 关于操作术语的说明

该电池棒控制器固件采用双按钮操作机制。屏幕中间的按钮实际仅用于激活保护板，不参与操作流程。**左边的按钮为向上/确认键**，当用户短按（按压时长大于0.3秒且小于3秒）时为向上功能，此时菜单会往上移动一个条目。当用户长按时为确认功能，此时将会进入选择的菜单子项。**右边的按钮为向下/退出键**，当用户当用户短按（按压时长大于0.3秒且小于3秒）时为向下功能，此时菜单会往下移动一个条目。当用户长按时为退出功能，此时将退出本子菜单项并返回上一级。

## 关机状态下如何启动电池棒控制器

为了节约电力消耗，电池棒控制器并不会处于始终开启状态。默认情况下电池棒控制器处于关机状态，此时屏幕熄灭，控制器几乎不消耗电能。当控制器检测到电池棒的USB Type-C连接放电设备或者充电器后，控制器会立即唤醒并进入工作状态，因此大部分情况下不需要手动开启控制器。如果您确实需要手动开启控制器，则长按向上/确认键或者向下/退出键直到屏幕亮起并显示logo即可松开。此时电池棒控制器将会进行自我测试和初始化，初始化结束后将会进入到工作状态并显示主屏幕。

## 主屏幕、进入主设置菜单和快捷菜单

控制器在初始化结束后将会进入主屏幕，主屏幕左侧显示电池的电压、电流和功率信息，右侧则显示系统温度、当前充电Ah数、Wh数和充电时间。右下角则会显示电池当前的状态。当系统处于充电状态时，您可通过单击向上/确认键进入USB Type-C接口的实时状态监视（可以查看电压、电流和功率）以及当前输入协议和状态。单击向下/退出键即可返回主菜单。如果您要调整电池棒控制器的系统设置，则请同时按住向上/确认键以及向下/退出键3秒，此时系统将会进入设置菜单。如果您要进入快捷菜单，则长按向上/确认键即可进入。快捷菜单允许用户临时启用/禁用储存模式、并且开启仅充电和仅放电功能以及清除故障保护。

## 开关设置项类菜单操作（例如快捷菜单）

对于仅有开关两组状态的设置项，您进入菜单后可以通过短按向上/确认键或者向下/退出键选择您需要更改状态的条目。被选中的条目会以青色高亮显示，右边的开关标记则是当前该条目的状态。如果为绿色横杠则表示条目为使能状态，红色圈则表示该条目为除能（禁用）状态。选中要更改的条目之后可以通过长按向上/确认键改变条目的状态（每次长按3秒，条目状态会改变一次，例如当前条目是使能状态，长按后会变为除能状态。除能状态以此类推）。当所有菜单项编辑完毕后，长按向下/退出键将会退出菜单并返回上一级。

## 多选项类菜单操作（例如充放电功率设置项）

对于有多个可选项的设置项，您进入菜单后系统将会用青色高亮显示当前该设置项所对应的设置值。例如您进入充放电功率设置菜单后，100W的选项被青色高亮则表示系统当前的充放电功率设置为100W。此时您可以通过短按向上/确认键或者向下/退出键选择您想要的设置值，当选择好目标的设置值后长按向上/确认键即可保存。此时系统会提示设置已保存表示保存成功。如果您想放弃更改，则长按向下/退出键。此时系统将会无视您所做的更改并回到上一级菜单。

## 数值设置类菜单操作（例如电池充电电压等）

对于具体数值类的设置菜单，您进入后系统会显示具体数值。此时您可以通过单击向上键令数值增加一个单位（例如设置值是1到10范围，步进1则按一下则会令数值增加1）单击向下键则会令数值减少一个单位。如果您需要快速且大范围的增减数值，则可以长按向上键，此时系统会令数值快速增加。长按向下键则令数值快速减少。当数值调整到您所需的目标值时，同时按住向上和向下键并保持3秒以上，此时系统会保存您所做的更改并返回到上一级菜单。

## POST阶段代码显示

该电池棒控制器在每次上电之后，均会进行上电自我测试和初始化操作，并在屏幕右下角的自检进度条上方输出自检状态的代码。代码由两位ASCII字符组成，共分为初始化进程代码，错误代码和警告事项代码三种类型。与此同时，进度条的颜色会指示系统当前自检的情况。青色表示自检进行中，黄色表示自检过程中遇到异常，但是并非重大问题。如果自检进度条变为红色则说明系统遇到重大问题，此时进度条上方会显示问题类型。如果进度条变为橙色则说明自检过程中遇到特殊事件，系统将输出额外的提示信息。对于代码的具体含义请参考如下内容：

### 系统自检结束代码

+ AA：电池棒控制器所有初始化和自我测试已正常通过，没有异常信息输出，将进入正常运行模式
+ AB：电池棒控制器在初始化期间输出了需要用户注意的提示信息，自检已正常通过将进入正常运行模式
+ AC：电池棒控制器在初始化期间遇到部分自检项目出现问题，但不影响电池棒控制器运行，将进入正常运行模式

### 错误代码

+ E0：系统心跳定时器故障（检查代码）
+ E1：片内ADC自检异常（检查代码，无效则更换IC）
+ E2：电池端电流检测电路基准电压异常（检查硬件）
+ E3：板载NTC热敏电阻（测量系统温度）故障
+ E4：重试多次后充电IC唤醒操作仍然失败
+ E5：在初配置时对IC进行多次通信操作后仍然没有回应
+ E6：在初配置或后配置时读取芯片版本信息失败
+ E7：IP2366当前的芯片内固件版本不受支持，系统无法启动
+ E8：系统在读取外部存储器(EEPROM)时出现异常
+ E9：系统在写入外部存储器(EEPROM)时出现异常
+ EA：系统在读取外部存储器的安全密匙区域时出现异常
+ EB：系统检测到当前MCU片内运行的固件已被篡改，进入锁定模式
+ EC：系统在进行OTP安全密钥初始化操作时无法写入到安全扇区
+ ED：系统在初始化主动均衡控制器时遇到问题
+ EE：系统在恢复数据库缓存时无法将Guard Key写入到缓存内
+ EF：系统在恢复数据库缓存时无法对缓存数据域进行写入
+ F0：系统在尝试读取运行日志数据库时出现异常（可能是EEPROM问题）
+ F1：系统在充电芯片后配置时未能成功写入充电芯片的休眠配置
+ F2：系统在充电芯片后配置时未能成功写入充电芯片的再充电配置
+ F3：系统在充电芯片后配置时未能成功写入充电芯片的低电压关机保护配置
+ F4：系统在充电芯片后配置时未能成功写入充电芯片的对外放电系统配置

+ F6：系统在充电芯片后配置时未能成功写入充电芯片的对外PD Fixed输出广播配置
+ F7：系统在充电芯片后配置时未能成功写入充电芯片的对外PD Fixed挡位的电流配置
+ F8：系统在充电芯片后配置时未能成功写入充电芯片的对外PD PPS挡位的配置

### 警告事项代码

+ W0：上次系统启动时未正常关闭（可能是由于固件异常引起）
+ W1：电源管理IC唤醒失败，重试中
+ W2：系统正常工作所需的SMBUS从机通信超时
+ W3：在尝试对IP2366进行初步的寄存器配置时无法连接到IC
+ W4：系统内所有的配置文件都已损坏，系统将加载并尝试恢复到默认出厂配置
+ W5：系统检测到非法的电池端峰值电流配置，将进行自动修正
+ W6：系统检测到非法的PD输入配置，将进行自动修正
+ W7：系统在重建数据库时发现损坏的运行日志记录，将用初始值强制覆盖
+ W8：系统检测到电池电压异常，可能是电池未正确安装
+ W9：系统检测到非法的恒压充电截止电流配置，将进行自动修正
+ WA：系统检测到非法的20V PDO电流配置，将进行自动修正
+ WB：系统检测到备用配置区数据已损坏，将使用主用配置进行覆盖
+ WC：充电功率配置非法，超出2366芯片报告的能力，系统将修正结果
+ WD：系统Sink设置非法，已经自动进行修正
+ WE：系统涓流电压配置参数非法，已进行自动修正
+ WF：系统检测到当前电池包温度过低，已禁止电池充电，请等待电池包回温后再进行充电。

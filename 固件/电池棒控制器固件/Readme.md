# 电池棒控制器固件操作指引

## 关于操作术语的说明

该电池棒控制器固件采用双按钮操作机制。屏幕中间的按钮实际仅用于激活保护板，不参与操作流程。**左边的按钮为向上/确认键**，当用户短按（按压时长大于0.3秒且小于3秒）时为向上功能，此时菜单会往上移动一个条目。当用户长按时为确认功能，此时将会进入选择的菜单子项。**右边的按钮为向下/退出键**，当用户当用户短按（按压时长大于0.3秒且小于3秒）时为向下功能，此时菜单会往下移动一个条目。当用户长按时为退出功能，此时将退出本子菜单项并返回上一级。

## 关机状态下如何启动电池棒控制器

为了节约电力消耗，电池棒控制器并不会处于始终开启状态。默认情况下电池棒控制器处于关机状态，此时屏幕熄灭，控制器几乎不消耗电能。当控制器检测到电池棒的USB Type-C连接放电设备或者充电器后，控制器会立即唤醒并进入工作状态，因此大部分情况下不需要手动开启控制器。如果您确实需要手动开启控制器，则长按向上/确认键或者向下/退出键直到屏幕亮起并显示logo即可松开。此时电池棒控制器将会进行自我测试和初始化，初始化结束后将会进入到工作状态并显示主屏幕。

## 主屏幕、进入主设置菜单和快捷菜单

控制器在初始化结束后将会进入主屏幕，主屏幕左侧显示电池的电压、电流和功率信息，右侧则显示系统温度、当前充电Ah数、Wh数和充电时间。右下角则会显示电池当前的状态。当系统处于充电状态时，您可通过单击向上/确认键进入USB Type-C接口的实时状态监视（可以查看电压、电流和功率）以及当前输入协议和状态。单击向下/退出键即可返回主菜单。如果您要调整电池棒控制器的系统设置，则请同时按住向上/确认键以及向下/退出键3秒，此时系统将会进入设置菜单。如果您要进入快捷菜单，则长按向上/确认键即可进入。快捷菜单允许用户临时启用/禁用储存模式、并且开启仅充电和仅放电功能以及清除故障保护。

## 开关设置项类菜单操作（例如快捷菜单）

对于仅有开关两组状态的设置项，您进入菜单后可以通过短按向上/确认键或者向下/退出键选择您需要更改状态的条目。被选中的条目会以青色高亮显示，右边的开关标记则是当前该条目的状态。如果为绿色横杠则表示条目为使能状态，红色圈则表示该条目为除能（禁用）状态。选中要更改的条目之后可以通过长按向上/确认键改变条目的状态（每次长按3秒，条目状态会改变一次，例如当前条目是使能状态，长按后会变为除能状态。除能状态以此类推）。当所有菜单项编辑完毕后，长按向下/退出键将会退出菜单并返回上一级。

## 多选项类菜单操作（例如充放电功率设置项）

对于有多个可选项的设置项，您进入菜单后系统将会用青色高亮显示当前该设置项所对应的设置值。例如您进入充放电功率设置菜单后，100W的选项被青色高亮则表示系统当前的充放电功率设置为100W。此时您可以通过短按向上/确认键或者向下/退出键选择您想要的设置值，当选择好目标的设置值后长按向上/确认键即可保存。此时系统会提示设置已保存表示保存成功。如果您想放弃更改，则长按向下/退出键。此时系统将会无视您所做的更改并回到上一级菜单。

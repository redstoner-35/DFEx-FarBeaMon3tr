### 概述

Xtern Ripper HyperFanDriver(HFD)是一款全新设计的侧按单锂升压驱动12V暴力风扇驱动，针对本手电所选配的基于东东海F1A风扇辅助散热手柄半成品五金套料所实现的风扇主动散热手柄DLC而设计。相比于市面上使用成品手电驱动（例如飞翔尾按单锂升压6V LED驱动）魔改的版本具有更低的输出纹波和更高的稳定性。该驱动同时支持2线电压调速风扇和四线PWM风扇。单锂模式下使用单节21700锂电池即可实现30W实际功率的34000RPM风扇持续运行并让手电达到2万LM的持续常亮。

### 性能数据

+ 支持的电池输入类型：1-2S三元锂电池，持续放电能力应大于20安培。
+ 支持的风扇类型：12V额定工作电压的直流无刷风扇，2线电压调速或四线PWM调速均可
+ 支持的风扇电流和功率：单锂条件下30W(12V 2.5A) 双锂串联条件下72W(12V6A) **注意：本处所标称的电流为支持的风扇实际电流而非风扇标签上所写的电流，只要保证风扇的实际运行电流不超过限制即可。例如建准XF40281BX风扇的标签电流为3A，但实际运行电流为2.25A，此时风扇是可以正常使用的**
+ 电池保护：具有欠压自动降档和关机保护以及过电压保护


### 总体操作逻辑

该风扇驱动同时具备无级调速和阶梯挡位调速可以随时选择。同时还具备双击一键全速功能。对于风扇的操作逻辑可以参考如下：
![逻辑图](/img/FanOp.png)

对于图中的部分未详尽解释的特殊逻辑，则可参考如下内容：

+ 按键锁：关机状态下五击开关，侧按指示灯红色闪三次进入锁定模式，此时任何操作无效。**为了保证安全，进入锁定模式后即使重新安装电池，风扇也会始终保持在锁定状态。** 在锁定状态下再次五击，侧按指示灯绿色闪烁三次，并且风扇低速运转1.5秒，表示成功解锁，此时风扇可以正常操作。

+ 查询电量：任意状态下通过双击+长按进入。当进入电量查询模式后风扇的颈部开关指示灯首先将会以红黄绿依次点亮的方式作为先导提示，提示用户风扇即将开始显示电池电压和电量。延迟1秒后风扇将通过红色，黄色和绿色的指定次数的慢速闪烁（如果快速闪烁一次，则表示该数据位为0）提示用户当前的电池电压，播报完电池当前电压后，风扇将会在延迟2秒后通过后续的长亮(或者慢闪)提示用户当前电池电压对应的总体电量水平（指示方式参考下文中驱动位于正常工作时的指示），对于电池具体电压播报的计算方式请参考如下内容：
  - 红色闪烁次数+黄色闪烁次数x0.1+绿色闪烁次数x0.01=当前电池电压(V)，例如`红色慢闪4次-黄色慢闪1次-绿色慢闪3次`表示电池电压为4+1*0.1+3x0.01=4.13V。

+ 设置按键有源夜光功能：关机状态下七击按键，风扇的侧按指示灯以绿色快闪一次表示功能开启。若以红色快闪一次则表示功能关闭。该功能开启后，风扇手柄将会在闲置未用且电池电压充足的情况下令按键发出微弱绿光指示风扇手柄的开关位置。
+ 恢复出厂设置：在手柄处于断电状态下，持续按住按钮并装入电池。此时手柄的侧部按键指示灯将会以黄色的持续高频率快闪提示用户已恢复出厂设置。用户松开按键后2秒，手柄将会自动重启并进入正常工作状态。需要注意的是，恢复出厂设置并不能清除电池配置锁定。

### 电池参数配置

该风扇驱动同时支持单锂和双锂电的操作，在电池配置未锁定的情况下，风扇手柄可以自动检测双锂电的插入并切换为双锂电池模式。对于电池配置模式用户也可以随时进行调整。**需要注意的是，如果系统处于电压调速模式，则电池参数配置将不支持，且系统永远只能工作于单锂模式。** 对于如何确认系统当前的电池配置以及调整配置、识别系统异常等，请参考如下内容：

+ 识别系统当前的电池配置：在每次装入电池时，电量指示灯会进行自检并显示当前电池电量。如果当前系统开启了双锂电模式，则系统在装入电池后首先会以黄色快闪2次，延迟0.5秒后再显示电池电量（假设电量充足，则指示灯将绿色常亮3秒）。若当前为单锂模式，则驱动将会直接提示电池电量。
+ 双锂电自动识别功能：当系统处于单锂电模式且电池配置未锁定时，如果用户装入两节电池，则系统会检测到并自动切换至双锂模式。此时系统会通过绿色快速频闪2秒作为检测到双锂的提示，并在2秒后以双锂模式重新启动。
+ 电池状态异常识别：为了避免用户装入不匹配的电池导致驱动工作异常或者引起电池过度放电，系统会根据当前的电池配置对电池进行状态验证。如果您在装入电池后看到颈部开关以红色持续高频闪烁，则说明系统检测到电池异常，请检查电池是否和系统设置匹配。**例如，在单锂电模式下装入了2节电池，或在双锂电模式下装入了三节电池，都会触发保护。**
+ 切换单锂/双锂模式：在电池配置没有锁定的情况下，用户可以通过在关机状态下五击+长按切换单锂和双锂模式。当切换为单锂模式时，风扇手柄的侧按将会通过红色频闪一次提示已经成功切换。如果是切换为双锂模式，则扇手柄的侧按将会通过绿色频闪2次提示成功切换。**需要注意的是，如果系统当前安装了2节电池，为了保护电池避免过度放电，此时系统将会禁止用户切换为单节锂电池模式。如果您需要从双锂模式切换至单锂模式，请将电池取出并仅安装一节电池，再进行切换操作。**
+ 电池配置锁定：对于面向成品手电客户的场合，为了避免用户擅自更改电池配置引起问题，您可以在设置好系统的电池配置后对电池配置进行半永久性锁定。触发锁定的方法是在关机状态下连续八击按键，成功锁定后风扇手柄将会以绿色闪烁三次作为提示。在锁定后，用户将无法通过五击+长按的方式切换电池配置，同时系统也不会自动识别双锂电的装入并自动配置为双锂模式。**该锁定操作为半永久性操作，一旦执行将无法撤销。如果确实因为意外情况需要撤销，则需要重新刷写固件。**


### 风扇调速模式配置

该风扇驱动在硬件PCBA的背部有一个标识为P的电阻焊盘位置（如下图所示）用于设置固件的工作模式：
![逻辑图](/img/PWMRes.png)

在每次上电时，固件将会自动识别该电阻的状态并切换模式。该电阻安装时固件将会工作于PWM调速模式（该模式适配四线暴力风扇）。此时风扇驱动始终固定输出12V电压，风扇速度由驱动输出的PWM信号控制。**此时固件不支持使用只有电源线的2线或只有电源+转速反馈的3线风扇。如果强行使用会导致风扇始终全速无法调速！** 如果您需要使用`2线或3线的不支持PWM调速的风扇`则需要去除该电阻并配置为电压调速模式。此时系统将会禁用PWM信号输出并通过调控风扇电压对风扇速度进行控制。**需要注意的是，如果你的风扇是高转速暴力风扇，则因为风扇的启动电压通常较高导致电压模式下调速范围会极窄。此时将会出现部分挡位电压过低导致风扇无法启动的问题。因此作者建议在搭配暴力风扇使用时开启PWM调速模式。**

同时需要注意的是，由于该驱动仅支持升压，因此风扇电压应始终高于电池电压。为了保证电压模式下调速范围正常，如果您配置驱动使用电压调速模式，则驱动将会禁用双锂电支持。此时若装入两节锂电池，驱动将会拒绝运行并报错。仅四线PWM调速模式并搭配四线PWM风扇时，支持双锂电池运行。

### 编译固件时MCU的CONFIG配置

由于中微单片机内部有一组硬编码于Flash指定区域，用于设置单片机的硬件首选项（例如看门狗，调试模式，低电压保护点等）的配置Word。为了确保编译出来的固件可以在硬件内正常运行，您需要在工程配置(Options for Target 'XRFan'->Debug选项卡->右上角的Settings按钮)的Config设置菜单，按照下表正确填写MCU的配置。错误的CONFIG设置会引起固件工作异常！

+ Power                      :  Inter 5V            
+ WDT                        :  SOFTWARECONTROL     
+ PROTECT                    :  ENABLE              
+ FLASH_DATA_PROTECT         :  ENABLE              
+ LVR                        :  3.5V                
+ DEBUG                      :  Disable             
+ OSC                        :  HSI                 
+ OSC_PRESCALE               :  Fosc/1              
+ HSI_FS                     :  Fhsi/1              
+ EXT_RESET                  :  DISABLE             
+ EXT_RESETSEL               :  P00                 
+ WAKEUP_WAITTIME            :  500us               
+ CPU_WAITCLOCK              :  2T                  
+ WRITE_PROTECT[0-2K]        :  DISABLE             
+ WRITE_PROTECT[2-4K]        :  DISABLE             
+ WRITE_PROTECT[4-6K]        :  DISABLE             
+ WRITE_PROTECT[6-8K]        :  DISABLE             
+ WRITE_PROTECT[8-10K]       :  DISABLE             
+ WRITE_PROTECT[10-12K]      :  DISABLE             
+ WRITE_PROTECT[12-14K]      :  DISABLE             
+ WRITE_PROTECT[14-16K]      :  DISABLE             
+ BOOT                       :  BOOT_DIS

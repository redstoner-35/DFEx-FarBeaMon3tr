### 概述

欢迎来到由Redstoner_35所开发的新一代高功率全恒流远射/远泛手电**DFEX-FarBeaMon3tr**的完整设计开源仓库。DFEX-FarBeaMon3tr是基于XTR HyperBoost超高能效升压恒流驱动所实现的大型手电参考设计，该手电采用全铝合金CNC设计，内置6节21700的可换电池电池架。电池架具备保护板、主动均衡和被动均衡确保使用安全，同时利用定制版本的充电系统支持高达140W输入功率的快速充电，缩短了极亮完毕后的补能时间。利用了全新的高功率双相交错升压恒流平台，该手电可实现高达760W的极亮功率。并且通过夜巡者7175灯珠得到72000lm 0.8M CD(或者使用定制的FL7018I灯珠得到75000LM 120万CD)的出光性能。同时无风条件下可实现6000-7000lm的恒流持续常亮，或在配合高功率风扇手柄的条件下以18000LM的亮度恒流持续常亮，直到电池电量用尽。该手电方案基于本人完全自主设计的硬件平台和软件系统，故具有超越市面上量产产品的极致性能以及稳定性，同时借助定制的软件系统可以实现市面上量产手电无法企及的高度可定制性和丰富功能。

### 复刻时电池的选择

这个手电的电池在工作过程中需要承受巨大的电流。对于使用7175灯珠和36A电流配置的远泛版本，电池电流可能会高达80A，也就是每节电池需要提供40A的电流。如此巨大的电流基本不允许使用非全极耳的动力电芯。经过测试，我建议使用如下的电芯：

+ 天鹏能源50XG：目前最强的5000容量全极耳电芯。正A品价格22-30之间。不管是充电还是放电水平都属于业界T0梯队，强烈推荐！ **但是需要注意不要买到早期测试报废品（正A品的电池皮是灰色的）测试报废品会漏电导致电池架工作异常！**
+ 瑞恩RS50：5000挡位全极耳电芯。A品价格大概20-25一节。该电芯充放电性能较为均衡属于兼顾容量和性能的动力电芯，在50XG出来后倒是不推荐了。
+ 比克INA21700-45D：高容量动力电芯。价格较贵约27一节，4500mA容量可以换来较长的续航。购买时建议选择A03高容品并特挑2.9毫欧内阻。
+ 新能安JP40：中等容量动力电芯，优势是货源数量极大因此价格很便宜，全新约15-20元一节。**需要注意的是，由于电池架的结构设计，拆机电芯因为电极表面不平整会导致电池架接触不良出现极亮瞬间保护等问题。因此不建议购买拆机的电芯。**
+ 三杰40Y：2025年三杰新推出的全极耳电芯，零售大概在20-25一节。性能相比前两者比较差，不推到700W以上问题不大。

可以用但是因为容易买到不好品质而不推荐的电芯：

+ 亿纬40PL：放电能力等于新能安JP40但是容易买到刮码降级B品，B品一致性差而且存在漏电问题，会导致手电工作异常。
+ 亿纬50PL：目前最强放电能力，且具有5000mAh的高容量。但是这款电芯目前产能和良率存在问题导致正A品一票难求。市场上目前只有降级刮码B品，一致性差而且存在单体漏电可能，会导致手电异常。

**注意：因为该手电极高的充放电倍率，绝对不要使用容量型或者半动力型电芯，是真的会爆炸！非要强行使用炸了后果自负，作者不承担任何责任！**

![风扇手柄正面](/img/%E9%A3%8E%E6%89%87%E6%89%8B%E6%9F%84%E6%AD%A3%E9%9D%A2.jpg)
![风扇手柄侧面](/img/%E9%A3%8E%E6%89%87%E6%89%8B%E6%9F%84%E4%BE%A7%E9%9D%A2.PNG)

该风扇手柄DLC基于自主开发的单锂升压12V风扇专用驱动以及单锂双向充电板，手柄样机所标配的风扇为建准的XF40281BX-Q035-S9H。转速高达34000RPM可以实现2万LM常亮不降档。同时该风扇手柄的电池仓为免拆电池充电设计，旋下电池仓即可露出内置的双向USB-TypeC充电接口：

![USB充电接口](/img/USB%E5%85%85%E7%94%B5%E6%8E%A5%E5%8F%A3.PNG)

该充电接口支持双向5V 2.4A充放电。最高12W的输入或输出功率。除了能给风扇手柄充电以外在应急情况下还可以反向为手机或其他设备应急充电。拆下手柄后即可看到手柄电池仓正面的充放指示灯：

![正面指示灯位置](/img/%E6%89%8B%E6%9F%84%E7%94%B5%E6%B1%A0%E6%9E%B6%E6%8C%87%E7%A4%BA%E7%81%AF.PNG)

手柄的电池仓一共包含两个指示灯，其中一个为放电和电池电量指示灯（图中紫色并且以放字标识的LED）以及一个充电状态指示灯（图中黄色以充字标识）负责指示电池的充放电状态。当电池仓首次装入电池时，电量指示灯会1Hz慢闪四秒表示电池安装后系统处于激活锁定模式。此时C口不能对外放电，需要连接充电器充电后才可放电。这两个指示灯不会同时点亮，显示的逻辑如下：

+ 充电指示灯：正在充电时0.5Hz慢闪，充满后持续点亮
+ 放电和电量指示灯：正在放电且电量正常时常亮，正在放电且电量不足后1Hz慢闪（充电或者放电结束拔下线缆后，电量指示灯仍然会保持点亮或闪烁一段时间，用户无需理会。30秒后电量指示灯会自然熄灭）
